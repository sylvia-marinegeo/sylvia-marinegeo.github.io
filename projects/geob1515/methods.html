GeoB1515-1 · Research Methodology

Methods & Data Sources

An overview of the analytical methods, scientific computing workflows, and data sources used to investigate sediment core GeoB1515-1, including X-ray diffraction, Python-based data analysis, and geospatial visualization.

Sylvia Hwang · B.Sc. Marine Geosciences · Universität Bremen

Analytical Methods

X-ray Diffraction

Quantitative XRD measurements are examined to characterize carbonate mineral assemblages, assess mineral distributions with depth, and identify anomalous mineral occurrences for further investigation.

Scientific Computing

Python and Jupyter notebooks support data cleaning, exploratory analysis, statistical comparisons, and scientific visualization. These workflows include quantitative mineralogical analysis, oxygen isotope stratigraphy, chronological interpolation, and evaluation of provisional age–depth relationships against published reference records.

Geospatial Context

QGIS is used to map the core location and examine its geographic and bathymetric setting within the western equatorial Atlantic.

Research Repository

Project documentation and analysis code are available in the public GitHub repository. Unpublished quantitative XRD measurements are excluded.

Data Availability & Attribution

The quantitative XRD dataset used in this project is unpublished and is not available for public download.

Please contact Dr. Christoph Vogt, Faculty of Geosciences (FB05), University of Bremen, for access to the full dataset.

Data Processing & Visualization

Python, pandas, NumPy, and Matplotlib were used for data processing, exploratory analysis, statistical comparisons, and visualization of mineralogical and isotope measurements. Chronological analyses included interpolation between published age constraints, sedimentation-rate calculations, extrapolation, and comparison with the LR04 reference stack.
